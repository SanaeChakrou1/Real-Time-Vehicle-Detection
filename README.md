# Real-Time Vehicle Detection and Counting

Real-time system for detecting and counting **vehicles** in videos using **YOLOv8**, **Deep Learning**, and **Computer Vision**.

## 🚀 Overview
This project implements a **real-time vehicle detection and counting system** that tracks vehicles across video frames. It is built in **Python** and optimized for speed and accuracy using YOLOv8.

## 🛠 Features
- Detects and counts vehicles in real-time videos
- Tracks vehicles across frames
- Displays a live count of vehicles crossing a designated line
- Annotated output video saved automatically
- GPU support for faster processing

## 💻 Technologies Used
- Python 3.10+
- [Ultralytics YOLOv8](https://github.com/ultralytics/ultralytics)
- [Supervision](https://github.com/roboflow/supervision)
- OpenCV
- PyTorch
